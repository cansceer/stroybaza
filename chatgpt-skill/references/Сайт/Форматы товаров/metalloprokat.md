# Формат «Металлопрокат»

Версия: 2026-11-26.1. Статус: опубликованные изображения сайта, проверенные 2026-11-26.

Композиция выбирается отдельно от раздела и геометрии SKU. [Общий порядок](README.md).

## Правила

- Явный запрос «Профили для ГКЛ по формату металлопроката» выбирает семейство metalloprokat; ПН/ПС/ПП используют подвариант open-profiles, не трубу и не листовой формат.
- Подвесы, крабы, соединители и удлинители не вытягивать в длинномер. Для них сохранять предметную постановку своего SKU; обозначить исключение в плане. При необходимости точного нового компактного шаблона запросить эталон только для этих позиций.
- Количество видимых повторов — композиционный приём, а не утверждение о комплектности продажи. Не добавлять к товару отсутствующий компонент.
- Координаты различаются между подвариантами; не навязывать всему металлопрокату y=208. Сохранять вертикальные оси, пропорции сечения, масштабы и просветы выбранного образца.
