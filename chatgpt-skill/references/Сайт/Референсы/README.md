# Референсы сайта

Здесь находятся только визуальные образцы сайта; правила и инструкции собраны отдельно в `Сайт/Инструкции`, а дизайн-код и брендбук — в `Сайт/Дизайн-код`.

- `Тизеры категорий/` — изображения товарных тизеров каталога; `vetonit.webp` — утверждённый эталон композиции мешков.
- `Изображения товаров/` — по одному изображению из товарной карточки на каждую основную категорию; описания и ссылки — в [README подборки](Изображения%20товаров/README.md).
- `Акции и офферы/`, `Превью акций/` — примеры изображений промо.
- `Превью статей/`, `Страницы статей/` — примеры визуалов блога.
- `Боковые баннеры/` — шаблон подложки и примеры размещения.

Копии изображений в навыке оптимизированы в WebP. Формат результата для новых материалов определяется соответствующей инструкцией.
