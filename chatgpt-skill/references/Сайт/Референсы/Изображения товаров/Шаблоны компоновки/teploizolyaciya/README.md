# Композиционные референсы: вертикальная упаковка утеплителя

## Основной вариант — Knauf Teplo

[Открыть референс](uteplitel-upright-3-4.webp)

Это шаблон для вытянутой мягкой упаковки утеплителя: почти вертикальная постановка, умеренный ракурс 3/4, видимая правая грань, верхний отступ 105 px и намеренный выход упаковки за нижнюю границу квадратного холста 1000 × 1000 px.

## Дополнительный вариант — ТИСМА S38MR

[Открыть утверждённый референс](uteplitel-tisma-s38mr-upright-3-4.webp)

Этот вариант также утверждён. Лицевая плоскость смотрит почти прямо на зрителя, справа читается боковая грань, сверху виден торец с минеральной ватой. Вертикальное положение, реалистичный объём пачки и нижний выход за край сохраняются. Для ТИСМА и упаковок близкой геометрии ориентироваться на масштаб и верхний отступ этого изображения; не переносить на него координаты шаблона Knauf Teplo.

Оба изображения показывают компоновку, а не универсальную маркировку. Для каждого SKU сохранять именно его упаковку, цвет и печать по карточке или исходному фото. Не переносить логотипы и надписи между брендами.

Для похожих по форме упаковок смежных категорий выберите наиболее близкий по геометрии пример. Референс задаёт ракурс и кадрирование, но не заменяет товарный референс конкретного SKU. Сверяйте форму, материал, цвет, логотипы и маркировку с фотографией самого товара. Для XPS/пенопласта в плитах, листовых материалов, отдельных рулонов и другой геометрии используйте соответствующий отдельный шаблон.
