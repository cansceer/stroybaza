# Референсы боковых баннеров

- `back.svg` — общая подложка: верхняя серая зона с паттерном и нижняя белая зона под текст.
- `banner-project-m.webp`, `banner-project-s.webp`, `banner-project-t.webp`, `banner-project-v.webp` — визуальные примеры компоновки и картинки в баннере. Суффиксы этих референсов не задают город и не являются правилом именования финальных файлов.

Для готовых городских материалов использовать формат имени `banner-project-<город>.webp`, где `<город>` совпадает с доменной частью, например `banner-project-samara.webp`. Требования к размеру, качеству и верстке — в `Сайт/Инструкции/Правила боковых баннеров.md`.
