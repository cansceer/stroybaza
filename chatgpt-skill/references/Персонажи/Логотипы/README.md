# Логотипы Стройбазы

> **Обязательное правило:** соблюдать [универсальный дизайн-код](../../Общие%20правила%20%28алгоритм%29/Дизайн-код/Дизайн-код%20проекта%20Стройбаза.md) и [брендбук проекта](../../Общие%20правила%20%28алгоритм%29/Дизайн-код/Брендбук%20проекта%20Стройбаза.md). Эта инструкция уточняет канон персонажей и применима вместе с ними.


Здесь собраны рабочие копии оригинальных SVG-вариантов для персонажных задач. Основной источник логотипов всего проекта — `Общие правила (алгоритм)/Дизайн-код/Логотипы`; при расхождении сверять с ним и синхронизировать копии. Сохранять исходные пропорции и рисунок; не перерисовывать логотип, не генерировать его нейросетью и не набирать название вручную.

## Добавленные варианты
- `logo-accent.svg`, `logo-black.svg`, `logo-white.svg` — горизонтальные версии, холст 302 × 86.
- `logo-accent-compact.svg`, `logo-gray-compact.svg`, `logo-white-compact.svg` — компактные версии, холст 128 × 128.
- `logo-black-compact.svg` — компактная версия, холст 152 × 140.

Для одежды выбирать компактный SVG по контрасту ткани и масштабу реальной вышивки/нашивки. Учитывать перспективу, фактуру и светотень; логотип не должен доминировать. Полные горизонтальные версии с названием подходят для папок, карточек, каталогов и других отдельных носителей.

В папке также есть светлые и тёмные одно- и двухстрочные варианты `светлый-лого-*.svg` и `темный-лого-*.svg`. Выбирать оригинальный вариант по контрасту и доступному месту. Новые `logo-*.svg` — дополнительные фирменные варианты; не переименовывать и не менять их содержимое.
