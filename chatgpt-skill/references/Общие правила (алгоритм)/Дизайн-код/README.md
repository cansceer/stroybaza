# Общая визуальная система проекта «Стройбаза»

В корне этой папки находятся универсальный [дизайн-код](Дизайн-код%20проекта%20Стройбаза.md) и [брендбук](Брендбук%20проекта%20Стройбаза.md). Они обязательны для любых задач проекта.

- `Логотипы/` — официальные исходники логотипов SVG, общие для всех направлений.
- Специализированные инструкции и референсы хранятся в папках соответствующих направлений, отдельно от правил.

Локальные копии SVG могут находиться в рабочих папках отдельных направлений; при расхождении сверяться с общей папкой `Логотипы/`.
