# Официальные логотипы проекта «Стройбаза»

В этой папке лежат оригинальные утверждённые SVG-версии логотипа — единый источник для всех направлений проекта. Здесь находятся светлые, тёмные и акцентные версии, полные и компактные варианты.

Использовать именно эти SVG; не перерисовывать, не собирать из текста, не менять пропорции, цветовые сочетания или элементы. При расхождении с копиями в `Персонажи/Логотипы` и `Реклама/Ресурсы/Лого` источником истины остаются файлы этой папки.

Правила применения находятся в соседних документах `../Дизайн-код проекта Стройбаза.md` и `../Брендбук проекта Стройбаза.md`.
