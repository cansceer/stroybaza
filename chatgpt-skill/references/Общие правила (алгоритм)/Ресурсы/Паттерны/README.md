# Общие паттерны проекта

Здесь хранятся исходные файлы фирменных паттернов, общие для любых направлений Стройбазы. Использовать оригиналы из этой папки, сохраняя рисунок, масштаб и фирменные цвета.

Форматные шаблоны (например, фоновые SVG рекламных креативов и подложка бокового баннера) могут содержать собственные встроенные паттерны. Их продолжать использовать по соответствующим инструкциям; не заменять встроенный узор без задачи. Эта папка — центральная библиотека исходных паттернов.
