# Ресурсы проекта

Пользоваться ресурсами вместе с обязательными [универсальным дизайн-кодом](../Дизайн-код/Дизайн-код%20проекта%20Стройбаза.md) и [брендбуком](../Дизайн-код/Брендбук%20проекта%20Стройбаза.md).

## Шрифты
В папке `Шрифты` лежат официальные variable TTF-файлы с поддержкой кириллицы и лицензиями SIL Open Font License (OFL):

- `Шрифты/Unbounded/Unbounded[wght].ttf` — для заголовков, набирать ЗАГЛАВНЫМИ. Файл variable, диапазон веса 200–900.
- `Шрифты/Montserrat/Montserrat[wght].ttf` — для основного текста. Использовать начертание Regular, вес 400. Файл variable, диапазон веса 100–900.

OFL.txt в каждой папке шрифта — лицензия, сохранять вместе с файлом шрифта.

## Цвета
- Светлый: `#FFFFFF`
- Линейный градиент: `#373434` → `#000000`
- Тёмный однотонный: `#1A1A1A`
- Фирменный акцент героев и логотипа: `#B5AA7D`

Исходники общих фирменных паттернов хранить в `Общие правила (алгоритм)/Ресурсы/Паттерны`. Пока в папку не добавлены отдельные исходники, использовать встроенные варианты в форматных шаблонах: фоновые SVG в `Реклама/Ресурсы` и подложку `Сайт/Референсы/Боковые баннеры/back.svg`. Знак X обязателен в рекламных креативах и всегда располагается позади персонажей и товаров.
