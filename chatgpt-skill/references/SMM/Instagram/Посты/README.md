# Каталог шаблонов Instagram

**Макеты в этой папке фиксированные.** Выбрать вариант по типу задачи и сохранять расположение элементов, их пропорции, зоны и порядок. Названия ниже помогают найти макет; изображения — визуальный эталон. Подробные требования — в [Дизайн-коде SMM](../../Инструкции/Дизайн-код%20SMM.md) и [правилах оформления](../../Инструкции/Правила%20оформления%20SMM-постов%20и%20каруселей.md).

## Карусель: подборка строительных материалов

Папка [Карусель-подборка-материалов](Карусель-подборка-материалов/) содержит три отдельных фиксированных товарных раскладки:

1. [кровельные-материалы-обложка.webp](Карусель-подборка-материалов/кровельные-материалы-обложка.webp) — заголовок сверху, главный товар крупно на светлом фоне, сопутствующие упаковки по краям, угловая фирменная геометрия внизу.
2. [утеплитель-veonit-пример-размещения.webp](Карусель-подборка-материалов/утеплитель-veonit-пример-размещения.webp) — тёмная карточка, выбранная упаковка по центру, другие товары частично видны у краёв, короткая служебная строка сверху.
3. [утеплитель-knauf-пример-размещения.webp](Карусель-подборка-материалов/утеплитель-knauf-пример-размещения.webp) — светлая карточка, выбранная упаковка по центру, соседний продукт частично виден у края, паттерн внизу.

## Карусели: персонаж и материалы

Папка [Карусель-доска-и-сотрудник](Карусель-доска-и-сотрудник/) сохраняет три композиции:

1. [доска-обрезная-обложка-сотрудник.webp](Карусель-доска-и-сотрудник/доска-обрезная-обложка-сотрудник.webp) — тёмная обложка, заголовок сверху слева, сотрудник с доской справа, логотип снизу.
2. [сотрудник-и-кирпич-палета-пример.webp](Карусель-доска-и-сотрудник/сотрудник-и-кирпич-палета-пример.webp) — светлая композиция с сотрудником и палетой кирпича, фигура и материал разведены по сторонам.
3. [пакет-досок-пример-композиции.webp](Карусель-доска-и-сотрудник/пакет-досок-пример-композиции.webp) — пачка досок на светлой подложке с фирменной геометрией.

Папка [Карусель-стройматериалы-и-композиции](Карусель-стройматериалы-и-композиции/) содержит дополнительные варианты:

1. [сотрудник-с-доской-пример.webp](Карусель-стройматериалы-и-композиции/сотрудник-с-доской-пример.webp) — тёмная обложка, заголовок слева сверху, сотрудник с доской справа.
2. [сотрудник-и-кирпич-пример.webp](Карусель-стройматериалы-и-композиции/сотрудник-и-кирпич-пример.webp) — ч/б сотрудник и отдельно поставленная палета кирпича на светлом фоне.
3. [пакет-досок-на-темном-фоне-пример.webp](Карусель-стройматериалы-и-композиции/пакет-досок-на-темном-фоне-пример.webp) — пачка досок на тёмном фоне с паттерном.

## Карусель: товар Isover

В папке [Карусель-утеплитель-isover](Карусель-утеплитель-isover/) три связанных фиксированных макета:

1. [isover-теплая-крыша-обложка.webp](Карусель-утеплитель-isover/isover-теплая-крыша-обложка.webp) — светлая обложка товара; заголовок сверху, упаковка внизу.
2. [isover-характеристики-пример.webp](Карусель-утеплитель-isover/isover-характеристики-пример.webp) — светлая таблица параметров сверху, товарная упаковка в нижней зоне.
3. [isover-способ-применения-пример.webp](Карусель-утеплитель-isover/isover-способ-применения-пример.webp) — светлая текстовая карточка инструкции с фиксированным заголовком, текстовым блоком и геометрическим паттерном внизу.

## Сетка и сторис

- [Сетка Instagram](../Сетка/сетка-инстаграм.webp) показывает общий вид ленты и сочетание светлых/тёмных карточек. Учитывать ритм ленты, но не подменять им шаблоны отдельных публикаций.
- [Сторис акции «5 мешков Боларс»](../Сторис/акция-5-мешков-боларс.webp) — отдельный вертикальный шаблон. Не переносить расположение элементов поста на сторис без пересборки.
