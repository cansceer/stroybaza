# SMM Стройбазы

Рабочая папка материалов для социальных сетей. Сейчас примеры собраны в `Instagram`.

## С чего начать

- Обязательный визуальный стандарт: [Дизайн-код SMM](Инструкции/Дизайн-код%20SMM.md).
- Практические требования к постам, сторис и каруселям: [Правила оформления SMM-постов и каруселей](Инструкции/Правила%20оформления%20SMM-постов%20и%20каруселей.md).
- Персонажей использовать по исходникам и правилам в общей папке [Персонажи](../Персонажи/).
- Общие SVG-логотипы и варианты паттернов Instagram находятся в [Instagram/Ресурсы](Instagram/Ресурсы/).
- Посты и карусели переименованы по содержанию; карусели сохранены в отдельных папках. Макеты фиксированные: см. [каталог всех вариантов](Instagram/Посты/README.md), выбирай подходящий и сохраняй его композицию.
