# Ресурсы рекламных креативов

Соблюдать [универсальный дизайн-код проекта](../../Общие%20правила%20%28алгоритм%29/Дизайн-код/Дизайн-код%20проекта%20Стройбаза.md), [брендбук проекта](../../Общие%20правила%20%28алгоритм%29/Дизайн-код/Брендбук%20проекта%20Стройбаза.md) и `Реклама/Инструкции/Правила рекламных креативов.md`.

- `Товарный креатив/` — фоновые SVG для товарных композиций. Есть светлые и тёмные шаблоны пяти размеров. Выбирайте сочетание фона, паттерна и X для макета.
- `Креатив с персонажами/` — единственный источник готовых фоновых SVG для креативов с персонажами. Использовать только добавленные сюда варианты. Светлые шаблоны есть для 1080 × 607 и 1000 × 1000 px; для 850 × 640, 640 × 850 и 632 × 980 px светлых шаблонов нет, доступны тёмные. Не подменять отсутствующий светлый шаблон фоном из `Товарный креатив/`, не собирать и не добавлять новые варианты без отдельного референса/файла. X обязателен и должен оставаться позади фигур и товаров.
- `Лого/` — оригинальные словесные SVG-логотипы, используемые в рекламных референсах. `светлый` — белое начертание для тёмного фона; `темный` — чёрное начертание для светлого фона. Название указывает на цвет логотипа, не фона. Выбирать одно- или двухстрочную версию, размер и положение по референсам. Полные фирменные варианты для других носителей находятся в `Общие правила (алгоритм)/Дизайн-код/Логотипы`; логотипы не перерисовывать и не редактировать.

SVG — исходные слои/шаблоны, а не итоговый формат выдачи: готовые рекламные креативы сохранять в JPEG, согласно инструкции.





**Сборка:** SVG-фоны здесь — утверждённые неизменяемые шаблоны, а не подсказка для перерисовки. Используйте шаблон точного размера и допустимого варианта как фоновый слой. Генератор изображений не должен рисовать весь креатив, логотип, оффер, знак X, паттерн или фон. Добавляйте отдельными слоями только товар/персонажа, оригинальный логотип и типографику. Если точную послойную сборку выполнить нельзя, не выдавайте приближение за готовый макет.
