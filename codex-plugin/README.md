# Плагин Codex «Стройбаза»

Плагин подключает навык проекта «Стройбаза»: он направляет Codex к локальным правилам, референсам и исходникам. При запросе на Figma используется отдельный сценарий создания нативного редактируемого полотна; статичный экспорт выдаётся отдельно.

Пошаговая инструкция для пользователей находится в [Установка плагина Codex.md](../../../Установка%20плагина%20Codex.md). Для работы нужны и плагин, и полная папка `stroybaza` с ресурсами проекта.
