# Формат «Пенопласт»

Версия: 2026-11-26.1. Статус: опубликованные изображения сайта, проверенные 2026-11-26.

Композиция выбирается отдельно от раздела и геометрии SKU. [Общий порядок](README.md).

## Правила

- Толщину, плотность, размеры и фасадное назначение брать из SKU; видимые гранулы не заменять гладкой фактурой XPS.
- Сохранять реальную форму листа, число плит и перекрытия эталона; не переносить формулу усиления ОСБ без отдельного указания.
- В опубликованном источнике есть едва видимые пиксели около y=20. Они не задают верх товара: направляющая снимается по alpha>8, с визуальной проверкой, новые экспорты без случайного ореола.

## Подварианты и измеренные эталоны

### Три плиты ППС — `eps-plates`

Три вертикальных перекрывающихся плиты с читаемой зернистой белой структурой и собственными кромками. Основной контур alpha>8: x≈144…857, y≈214…1000.

- [Изображение-эталон](../%D0%A0%D0%B5%D1%84%D0%B5%D1%80%D0%B5%D0%BD%D1%81%D1%8B/%D0%98%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%20%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2/%D0%9F%D0%BE%D0%B4%D0%BA%D0%B0%D1%82%D0%B5%D0%B3%D0%BE%D1%80%D0%B8%D0%B8/teploizolyaciya--penoplast/penoplast-pps-8-r-a-1000kh1000kh20mm.webp); источник: [карточка товара](https://stroybaza-samara.ru/catalog/product/penoplast-pps-8-r-a-1000kh1000kh20mm/).
- Запись источника: `catalog-073`. Нативный холст: [1000, 1000]; основной альфа-контур при alpha>8: [144, 214, 857, 1000]; нормировано к 1000×1000: [144.0, 214.0, 857.0, 1000.0].
- Границы записаны как `[left, top, right, bottom]`; right/bottom — исключающие границы. Это направляющие выбранного образца, а не повод деформировать иной SKU. При новом размере/сечении сохранять постановку и пропорции; буквенное совпадение прямоугольника не заменяет визуальную проверку.
