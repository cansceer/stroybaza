# Редактируемый файл Figma

Общий сценарий находится в [инструкции Figma](Общие%20правила%20%28алгоритм%29/Инструкции/figma-editable.md). Перед вызовами интеграции прочитай доступные навыки `figma:figma-use` и `figma:figma-create-new-file`, если создаётся новый файл. Отдельное подключение Figma обязательно; плоский экспорт не является редактируемым макетом.
